# 阿里云配置指南

新版应用使用两个独立的阿里云服务：百炼识别我方中文及电话回传英语，机器翻译负责英译中及中译英。手机系统合成英语 WAV 文件，通过电话网关发给对方。百炼 API Key 与阿里云 AccessKey 是两种凭据，不能互换。

## 1. 开通北京地域的百炼

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，完成账号实名认证，并按控制台提示开通模型服务。
2. 选择 **华北 2（北京）**。本项目使用的 `paraformer-realtime-v2` 接口要求北京地域。
3. 进入所用业务空间，在业务空间管理或详情中找到 **业务空间 ID（Workspace ID）**，复制 ID，不要复制名称或控制台网址。
4. 在该地域的 API Key 管理页面创建 API Key，确保它有该业务空间及 Paraformer 模型的调用权限。复制并妥善保存完整 Key。
5. 在模型或用量页面确认可以调用 `paraformer-realtime-v2`，并核对当前账号的免费额度、可用余额和按量计费状态。

控制台页面名称可能调整；可参照官方 [Paraformer WebSocket 接入指南](https://help.aliyun.com/zh/model-studio/websocket-for-paraformer-real-time-service)。本项目自动将业务空间 ID 组成北京地域的专属服务地址，无需另填地址。

## 2. 开通阿里云机器翻译

1. 登录 [机器翻译控制台](https://mt.console.aliyun.com/)，开通 **通用文本翻译**，确认中英互译及按量付费可用。
2. 在控制台的资源包、用量或费用页面确认每月免费字符额度是否已生效。
3. 进入 [RAM 控制台](https://ram.console.aliyun.com/)，创建一个用于此项目的 RAM 用户，并为其创建 AccessKey。复制 **AccessKey ID** 与 **AccessKey Secret**；Secret 通常只在创建时完整显示。
4. 给这个 RAM 用户授权调用通用翻译。可以创建以下自定义权限策略，并绑定到该用户：

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["alimt:TranslateGeneral"],
      "Resource": "*"
    }
  ]
}
```

该项目调用杭州机器翻译接口，直接在程序中固定地址，不需要在手机上填写地域。参考 [TranslateGeneral 官方接口说明](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translategeneral)。不要用主账号的全权限 AccessKey。

## 3. 在手机里填写

安装新版“电话翻译”，在页面下方填写：

| 手机字段 | 从哪里获取 |
| --- | --- |
| 百炼业务空间 ID（北京） | 百炼北京地域的业务空间详情 |
| 百炼 API Key（北京） | 百炼北京地域的 API Key 管理 |
| 机器翻译 AccessKey ID | RAM 用户 AccessKey 的 ID |
| 机器翻译 AccessKey Secret | 同一 RAM 用户 AccessKey 的 Secret |

还需按 [电话网关配置指南](电话网关配置指南.md) 填写网关地址及网关访问令牌，然后“保存配置”。输入完整国际号码并通过网关拨号，授予麦克风和通知权限。对方接听后英语语音自动转成中文显示。中文手动发送后自动翻译、合成并上传到线路；开启中文语音输入后，完成的识别句子自动发送。手机不会本机朗读英语，发送期间继续接收对方声音。

旧版 Azure 的配置不会自动迁移到新配置。修改配置前需要挂断。密钥经过 Android Keystore 加密后保存在手机，不需要发给开发者或粘贴进聊天。

## 4. 安装系统英语语音包

在手机“设置”中搜索“文字转语音”或“TTS”，选择可用的语音引擎，安装并测试英语（美国）语音包。建议使用离线英语语音包；应用不会调用阿里云语音合成接口。部分手机需要另外安装可用的系统语音引擎。

## 5. 费用与排查

截至 2026-10-11 核对的参考价格，实际额度资格和账单以账号控制台为准：

| 项目 | 免费额度 | 超出后的参考价格 |
| --- | --- | --- |
| 北京百炼 Paraformer 实时识别 v2 | 每月 36,000 秒，约 10 小时 | 0.00024 元/秒，约 0.864 元/小时 |
| 阿里云通用文本翻译 | 每月 100 万字符 | 50 元/100 万字符 |
| 手机离线英语合成 | 无云端 API 费用 | 由本机语音引擎提供，网关通话另计费 |

实时识别按上传音频计量，持续监听时的静音也会上传。中文语音输入和远端英语是两个独立任务，两路同时识别时用量需要相加。若两路累计识别 100 小时、翻译不超过 100 万字符，且两项免费额度均生效，识别与翻译参考费用约为 **77.76 元/月**；电话网关与服务器费用另计。0.288 元/小时是录音文件识别价格，不适用于本项目的实时收音。不用时挂断并关闭中文语音输入。

百炼价格来源：[模型计费](https://help.aliyun.com/zh/model-studio/model-pricing)。机器翻译额度与价格请在开通页及计费页再次核对。

- **百炼认证失败**：检查 API Key 是否属于北京地域，是否有这个业务空间权限，是否已失效。
- **识别任务被拒绝**：检查业务空间 ID、模型权限、服务开通与余额；远端识别失败会请求挂断，中文识别失败关闭语音输入，需要修正后重试。
- **识别网络连接中断**：应用最多重试五次；确认手机可以访问北京百炼的 WSS 接口。
- **英语译中文/中文译英语失败**：检查机器翻译是否开通、RAM 权限策略、AccessKey 是否正确及余额。若提示签名错误，还要检查手机日期时间。
- **英语语音合成不可用**：先在系统 TTS 设置里试听英语，再返回应用重试。引擎还需支持合成 PCM 16 位 WAV 文件。输入文字会保留，方便重新发送。
- **锁屏后停止收音**：检查该手机的后台运行和省电设置。厂商策略仍可能终止前台服务。

本版本用于个人试用。在对外分发前，机器翻译长期 AccessKey 应改为由服务端管理；本机加密不等于客户端长期密钥无法被提取。
