# 电话网关配置指南

本项目现在从应用拨号，网关呼叫对方普通电话。首个接入使用 Twilio Programmable Voice + 双向 Media Streams。目标是孟加拉国（+880）和马来西亚（+60）；目前没有网关账号或公网服务器，先用本地模拟模式验证界面和音频接口。

## 一、先在这台电脑运行模拟服务

现有环境已安装网关依赖。新电脑需要 Python 3.11+，在项目根目录执行：

```powershell
python -m venv .toolchain/gateway-venv
./.toolchain/gateway-venv/Scripts/python.exe -m pip install -r gateway/requirements.txt
```

启动模拟服务：

```powershell
powershell -ExecutionPolicy Bypass -File tools/start_gateway.ps1
```

此脚本固定使用 `mock`，仅绑定电脑回环地址，不会拨打真实号码。第一次运行在 `.toolchain/gateway-token.txt` 生成随机令牌；用文本编辑器打开并复制到手机的“网关访问令牌”字段。不要把令牌发到聊天中。关闭终端或按 Ctrl+C 停止服务。

连接 USB 调试手机，建立手机到电脑的端口转发：

```powershell
./.toolchain/android-sdk/platform-tools/adb.exe reverse tcp:8765 tcp:8765
```

手机中的“网关地址”填 `http://127.0.0.1:8765`，令牌填刚才文件中的内容。还需填写四项阿里云配置并安装英语语音包，点击“保存配置”。输入一个格式正确的 +880 或 +60 号码，再点拨号，应该明确显示“模拟通话”。号码不会被实际呼叫。

输入短句中文并发送，预期显示“模拟验证：译文音频已接收（未拨号、未远端播放）”。它验证真实的手机翻译、TTS 文件合成、上传及网关转换路径，但云服务本身仍需有效凭据。模拟模式不是免费的真实国际电话。

如需模拟对方说英语，准备一个英语 PCM 16 位 WAV 文件（8–48 kHz、单/双声道、不超过 60 秒），在模拟通话连接后运行：

```powershell
python tools/send_mock_audio.py 'D:\测试音频\english.wav'
```

工具读取本地令牌，确认服务是模拟模式，按实时节奏注入音频。手机应显示中文译文。它不会向真实通话注入测试声音，也不会录制电脑麦克风。

模拟网关测试可独立运行，不需要阿里云账号：

```powershell
./.toolchain/gateway-venv/Scripts/python.exe -m pytest gateway/tests -q
```

## 二、开通真实电话服务

1. 注册 [Twilio](https://www.twilio.com/try-twilio)，按账号要求完成验证。试用账号通常限制只能拨打已验证号码，具体可拨国家及试用余额以控制台为准；业务使用可能需要升级付费账号。
2. 在控制台的账号信息中获取 `Account SID` 和 `Auth Token`。它们只配置在网关服务器，手机填的是本项目独立生成的网关访问令牌。
3. 取得具有 Voice 能力、允许用于目标国家外呼的 Twilio 主叫号码，作为 `TWILIO_FROM_NUMBER`。购买号码会有号码月租及可能的资料要求，不需要为了拨给马来西亚或孟加拉国而默认购买当地号码。
4. 在 Voice 的 Geographic Permissions 中核对孟加拉国、马来西亚对应的外呼权限；只开放需要的目的地。资费和高风险号段权限以账号实际设置为准。
5. 马来西亚官方指南明确说明：**马来西亚本地的 verified caller ID 不支持用于拨给马来西亚**。不要仅把已有 +60 手机号验证为 Caller ID 就认为能作为本项目主叫；使用供应商允许的 Voice 主叫号码并核对路由要求。
6. 在账户内设置适当的预算提醒，核对呼叫记录及计费。应用不会自动重新拨号。

[马来西亚 Voice 指南](https://www.twilio.com/en-us/guidelines/my/voice)说明支持普通国际外呼。孟加拉国官方价格页列有外呼价格，但具体号码/运营商可达性、主叫规则及账号权限仍需在控制台或向 Twilio 支持核实，不能仅凭价格页保证每个号码都可达。

## 三、部署公网 HTTPS / WSS 网关

真实模式需要手机和 Twilio 都能访问的公网 HTTPS 域名，WebSocket 升级可用，服务器能连接 `api.twilio.com`。手机还需能访问阿里云北京百炼及机器翻译服务。只在电脑启动回环服务不能接收 Twilio 的公网音频连接。

服务器安装 Python 3.11+，复制本项目的 `gateway/` 到例如 `/opt/telephone-translator/gateway/`，在 `/opt/telephone-translator` 创建虚拟环境并安装：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r gateway/requirements.txt
```

参考 `gateway/.env.example` 设置服务器环境变量。文件不会被程序自动读取；可由 systemd 的 EnvironmentFile 加载，或在启动终端设置。

| 变量 | 填写内容 |
| --- | --- |
| GATEWAY_MODE | 真实模式填 `twilio`，本地模拟填 `mock` |
| GATEWAY_TOKEN | 随机 32–256 位字母、数字、下划线或连字符，手机填同一个值 |
| PUBLIC_BASE_URL | 实际公网 `https://域名`，不要加路径或查询参数 |
| TWILIO_ACCOUNT_SID | Twilio 账号 SID，通常以 AC 开头 |
| TWILIO_AUTH_TOKEN | 同一账号的 Auth Token |
| TWILIO_FROM_NUMBER | 允许外呼的 Voice 主叫号码，完整 +国际格式 |
| ALLOWED_PREFIXES | 默认 `+880,+60` |
| MAX_CALL_SECONDS | 默认 `1800`；可设 60–7200 秒 |

生成令牌可用：`python -c "import secrets; print(secrets.token_urlsafe(32))"`。真实环境使用独立令牌，限制保存凭据文件的权限，勿提交到代码库。

通过反向代理提供 HTTPS。`gateway/Caddyfile.example` 是 Caddy 示例，替换域名并将 DNS 指向服务器；让 Caddy 为域名取得有效证书、转发到 `127.0.0.1:8765`。开放公网 443 及证书申请所需端口，8765 仅在服务器回环监听。Caddy 支持 WebSocket 升级，其他代理也必须保留该功能。关闭代理访问日志中的敏感信息记录。

网关运行命令（在项目根目录、配置环境变量以后）：

```bash
.venv/bin/python -m uvicorn gateway.server:app --host 127.0.0.1 --port 8765 --workers 1 --ws-max-size 65536 --no-access-log
```

只能使用 **一个 worker**，不能开启开发热重载；当前会话保存在内存中，多实例需要另行实现共享状态和会话路由。`gateway/gateway.service.example` 提供 systemd 模板，使用独立的 `translator` 用户；创建该用户、设置目录权限，并将环境文件保存为 `/etc/telephone-translator.env`（限制为管理员可读），然后按模板的实际路径启用服务。

程序创建呼叫时会自动提供 TwiML 和回调地址，无需在主叫号码的“来电处理”中另填本项目地址：

- 双向音频：`wss://域名/twilio/media/会话ID`
- 状态回调：`https://域名/twilio/status/会话ID`
- 手机访问：`https://域名/v1/...` 与相应的 WebSocket

签名根据 `PUBLIC_BASE_URL` 校验，反向代理内网地址不能代替公网地址。服务验证 Twilio 签名、账号、Call SID、Stream SID、会话秘密及音频格式。请保留 `X-Twilio-Signature` 请求头和原始请求路径。

## 四、手机切换到真实模式

网关部署完成后，将手机网关地址改为公网 `https://域名`，令牌改为服务器中的 `GATEWAY_TOKEN`，保存配置。不用在手机输入 Twilio Auth Token。

填写完整国际号码：孟加拉国用 +880，马来西亚用 +60；国家码后的国内拨号前导 0 通常需要去掉，请核对完整号码。准备短句中文和话术，在应用内发起一次人工测试通话：

- 对方接普通电话，只应听到英语合成译文。
- 说中文时，对方不应听到中文原声。
- 对方用英语说话，我方界面应显示中文。
- 应用状态应在 Twilio 的 mark 确认后显示“电话线路已完成英语译文播放”。这确认线路播放队列完成，不表示对方一定听清。
- 点击挂断后在 Twilio 呼叫记录确认已结束；测试断网和退出应用时也需核对呼叫状态。

真实呼叫会产生费用，本次开发和自动测试没有发起任何付费外呼。新账号、主叫号码及公网地址就绪后，才能完成真实通话验收。

## 六、故障排查

- 连接网关失败：先确认服务运行、手机地址、访问令牌；本地模式确认 `adb reverse` 生效。真实模式检查证书与 WebSocket。
- 百炼认证或语音引擎失败：修正阿里云配置或安装英语 TTS。应用会先准备识别及 TTS，再请求真实拨号。
- 外呼失败、忙线或无人接听：检查 Twilio 呼叫记录、目标区号权限、试用限制和主叫号码。
- 对方已接听但音频未连接：检查 Twilio Debugger 和公网 WSS 升级，尤其 PUBLIC_BASE_URL、签名和代理路径。只有音频流连接成功后才允许发送。
- 音频被拒绝：系统 TTS 需生成受支持的 WAV，单句不超过 60 秒；将长话术分段。
- 挂断未确认：服务器会重试。立即检查 Twilio 控制台并结束仍在进行的呼叫；不要持续点击重拨。
- 锁屏后不工作：检查手机网络及后台运行设置。前台服务持有通话期间的 CPU 唤醒锁，但厂商省电限制仍需真机验证。
